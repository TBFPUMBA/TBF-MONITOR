# 🔥 TBF-MONITOR

> **Live Server Monitor for Termux — by TBFPUMBA**

Minimal, powerful server monitor. Track CPU, RAM, disk, network, visitors, and logs in real time.

---

## ⚡ Installation

```bash
git clone https://github.com/TBF-of/TBF-MONITOR.git
cd TBF-MONITOR
pip install -r requirements.txt
python3 tbf_monitor.py
```

---

📦 Dependencies

```bash
pip install rich
```

---

📌 How to use

1. Run: python3 tbf_monitor.py
2. Configure IP and port
3. Start server
4. Monitor system stats
